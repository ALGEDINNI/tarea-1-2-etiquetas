Etiqueta br

La etiqueta br produce un salto de línea dentro de un texto sin crear un nuevo párrafo.

La etiqueta hr representa una ruptura temática entre párrafos y se visualiza como una línea horizontal.

Etiqueta img

La etiqueta img permite incrustar imágenes en la web utilizando el atributo src para indicar la ruta y alt para el texto alternativo accesible.
