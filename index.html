Etiqueta img

La etiqueta img permite incrustar imágenes en la web utilizando el atributo src para indicar la ruta y alt para el texto alternativo accesible.

Etiqueta input

La etiqueta input se emplea en formularios para crear controles interactivos donde el usuario introduce datos según el atributo type.


Etiqueta link

La etiqueta link se ubica en el head y establece la relación con recursos externos, como la hoja de estilos styles.css para aplicar el diseño de la web.

El fondo gris claro y los estilos visuales de esta página se aplican gracias al enlace cargado con la etiqueta link.

Etiqueta meta

La etiqueta meta aporta metadatos sobre el documento HTML que son procesados por navegadores y motores de búsqueda.

  • meta charset: Define la codificación de caracteres universal UTF-8 para mostrar tildes y caracteres especiales correctamente.
  • meta viewport: Ajusta la escala y dimensiones en dispositivos móviles para lograr un diseño responsive.
  • meta description: Proporciona un resumen del sitio que los motores de búsqueda como Google muestran en los resultados.
